# PvP 匹配 Mod（MC 1.21.1 · Fabric 服务端）

一个纯服务端的 PvP 匹配 Mod：支持 **1v1 / 2v2 / 自由乱斗(FFA) / 相扑(Sumo) / 空岛战争(SkyWars) / 战桥(Bridge) / 幸运之柱(Lucky Pillar) / TNT 跑酷(TNT Run) / 心跳水立方(Heartbeat) / 烫手山芋(Hot Potato) / 起床战争(Bed Wars) / 村庄保卫战(Village Defense) / 色盲派对(Colorblind Party) / 死斗(Deathmatch) / 亦可赛艇(Boat Race) / Minecraft Party 2（移植中）/ 海岛攻防(Island Siege) / MyGO 枪战爆破** 共 22 种模式，支持**队列自动匹配**与**决斗挑战**，可自选**装备套件**（剑战 / 弓箭 / 全装备 / NoDebuff / 自定义 JSON 配置等），其中「1.8 经典」套件自带 **1.8.7 低版本战斗手感**。每场比赛在**专用虚空竞技场维度**中生成独立地形，结束后销毁重建。

- 原版客户端即可加入，**无需安装客户端 Mod**
- **游戏内 GUI 菜单操作**（无需记指令）：进服自动发一把「PvP 竞技场」指南针，右键打开菜单
- 进服自动显示「PvP 匹配 Mod vX.X.X」版本号，方便确认是否最新
- 所有消息为中文
- 战绩（胜/负/场次/胜率）持久化保存；系统内部另有一套**隐藏分**只用于弱侧补偿，不展示给玩家

## 游戏模式

### PvP 对战（自选套件）
- **1v1 / 2v2 / FFA / 相扑**，选择套件后加入队列
- **自由乱斗**：凑齐 3 人开始 60 秒倒计时，期间达到 6 人自动加速到 10 秒内开赛（人数不限，每人用自己的套件）
- **相扑**：不吃伤害只吃击退，落到平台下方 20 格淘汰（套件带一组末影珍珠可救回），最后一个留在场上的人获胜
- **「1.8 经典」套件**：模拟 1.8.7 手感——**无攻击冷却**、**无剑格挡**、**没有剑横扫**、投掷物不继承投掷者速度。这套手感跟着**套件**走而不是模式走（见 `MatchManager.usesLegacyCombat`）：在自由乱斗 / 死斗 / 1v1 里选它，照样按 1.8.7 打，不会退回高版本 PvP。套件内容：钻石剑 + 全套铁甲 + 8 金苹果 + 速度 II

### 空岛战争 (SkyWars)

每人一座出生岛，经中途岛搭路进入中央岛群。**2～4 人使用紧凑地图，5～8 人使用标准地图**；同局出生岛的半径、高度和抢中距离一致，掩体、支路及主题随机变化。正式空岛已采用立体地图，无需另选 Beta。采用生存模式搜箱和开局职业，**无攻击冷却、无剑格挡**；空岛剑斧按旧版伤害取舍，雪球和鱼竿命中可产生击退。

地图结构与材质主题分别抽取：主世界、地狱、冰原、末地均可出现六种中央结构，村庄使用独立街区地图。开局提示和侧边栏会显示本局结构名。每种结构都有按人数调整的版本，箱子使用统一的空岛物资表填充并参与补货。 中央主岛的直径与内部平台、桥网按约 **2.5 倍**扩大（水平尺度），最终圈同步适配；出生岛和中途岛按所需净距外移，同局各方向抢中距离一致。默认紧凑／标准村庄主岛半径为 **70／100 格**，极端配置会限制在单局区域内。

| 地图结构 | 地形与主要交战路线 |
| --- | --- |
| 层叠遗迹 | 上、中、下多层岛面，两侧坡道连接资源层 |
| 环形要塞 | 城墙环道、内院与中央高台，可从不同方向攻入 |
| 破碎群岛 | 分离小岛围绕中央核心，短桥和高低差提供多条转移路线 |
| 树冠营地 | 根部地面、树冠平台与木栈道构成立体林地 |
| 高架回廊 | 上下交叉桥网与桥头平台，利用侧向通路切换交战层 |
| 下沉矿坑 | 下沉盆地、多层环道和对向坡道，入口与坑内都能交战 |
| 空中村庄 | 房屋、街巷、广场及分散的露天物资点 |

- **开局选择**：玩家传送到自己岛上方 10 格的玻璃笼中，自动提示选择职业；**5 秒**后解除笼子，自然下落并免疫一次摔落伤害。未选择时默认**战士**。大厅可用 `/pvp professions` 提前查看职业的物品、数量和附魔。
- **出生岛与中途岛物资**：恢复旧版每箱独立抽取：保底 **2 小叠搭路方块（每叠 5～12 个）和 3 件铁／锁链装备（各次有 10% 概率升级钻石装）**，再从旧表抽取 **4～5 组**物资。武器、护甲、金装、工具、食物、药水与特殊道具按原权重生成。
- **中岛物资**：每箱从旧版中岛表抽取 **5～7 组**物资，以钻石装为主，保留金装、工具、药水等原物品；长矛用附忠诚 III、耐久 III 的三叉戟实现。
- **弓与烈焰弹**：弓恢复旧版附魔概率，触发力量附魔时Ⅰ～Ⅳ等概率抽取；冲击Ⅱ与火矢各有独立 10% 概率。烈焰弹外圈每组 **2～4 个**，中岛每组 **3～5 个**。
- **稀有物品**：秒人斧为锋利 255、剩余 1 耐久的金斧；出生岛和中途岛每箱独立抽取秒人斧／不死图腾，各约 **1%**。中岛每箱独立抽取鞘翅配 3 烟花／附魔金苹果／不死图腾，各约 **1%**；补货重新抽取。追踪罗盘指向最近敌人。
- **弱势补偿**：恢复原来的隐藏分排名补偿：最低者 2 档，三人以上对局次低者 1 档。出生岛及中途岛的保底装备有额外钻石升级概率，附魔概率每档提高 10 个百分点，另各有约 0.25% 机会额外抽到秒人斧或图腾；补货也按同一规则生成。
- **图腾救援**：背包中的图腾可抵挡致死伤害；掉虚空时在**实际淘汰高度上方 10 格**触发。消耗后恢复 **8 点生命（4 颗心）**并给予短暂保护，优先回到仍处于安全圈内的最近记录落脚点，失效时搜索附近安全地面；缩圈淘汰不能被图腾阻止。
- **立体路线**：中央下层留出通行净空，上层与下层各有两条不同方向的进攻路线；侧台、观察台和高低层箱子都参与初次物资分配及补货。矿工可以挖穿部分掩体开辟近路。
- **五种主题**：主世界、地狱、冰原、末地和村庄。各主题保留安全决战地面；村庄模板生成后会清理结构方块与拼图方块，房屋内、广场的 **8 个固定军械箱**及屋外空地箱全部使用中岛物资，补货规则一致。屋外空地箱按紧凑／标准地图增加 **4／8 个**，避开房屋、道路和岛缘。
- **对局收束**：默认第 **3 分钟**补货并开始缩圈；补货与开局使用同一套旧版物资表，外圈也会重新刷新装备。每次塌圈提前 **15 秒**预警，默认第 **6 分钟**收束至中央决战区；离开安全区后有 **3 秒**返回时间，超时淘汰。最后幸存者获胜。
- 凑齐 4 人触发开赛等待（最少 2 人、最多 8 人）；队列等待倒计时与入场后的 5 秒职业选择倒计时分别计算。

### 战桥 (The Bridge)
双基地隔虚空相望，中央一座 1 格宽桥，跳进对方基地中央的**球门洞**得 1 分，**先得 5 分获胜**；死亡立即原地重生，每个进球后全员回笼位 5 秒再放出，**玩家搭的方块不重置**（只能拆别人搭的，地图本体受保护）。配铁剑 / 弓+1 支箭（每 4 秒回 1 支）/ 效率 II 钻石镐 / 128 个队伍色陶瓦 / 8 金苹果 / 队伍色皮革甲。采用 1.8 低版本战斗。四种模式：**1v1 / 1v1v1v1 / 2v2 / 混战**（偶数人数平均分两队，2v2~4v4）。

### 趣味小游戏（空手开局）
- **幸运之柱 (Lucky Pillar)**：出生在 1 格宽、40 格高的基岩柱顶（间距 8 格需搭桥跨柱），柱顶下 40 格有一整圈"安全平台"（掉出平台下方 20 格才淘汰），**每局平台方块随机 10 种风格**（岩浆块/岩浆炼药锅/雪块细雪/蜘蛛网/沙子仙人掌/树叶/活版门/半砖/粘液蜂蜜/纯虚空），平台方块可自由破坏；**每 3 秒**全员随机获得 1 个物品（全物品纯随机），每 **45 秒**触发随机事件（一击必杀/箭雨/雷击/TNT 雨/位置交换/补给潮）；最后幸存者获胜
- **TNT 跑酷 (TNT Run)**：5 层彩色羊毛平台叠放（层距 6 格），**踩过的方块 0.25 秒后消失**（不会爆炸，只能靠踩落）；地面随机刷新火焰弹与 TNT 掉落物（捡起来砸人/炸人）；掉出底层淘汰，最后幸存者获胜
- **心跳水立方 (Heartbeat)**：高空出发台往下跳，5 层"心跳"棋盘格地板周期性**出现 3 秒 → 消失 1.5 秒**（配心跳音效与心形粒子），卡节奏逐层下落；底部 5 个圆形水坑，**落进水坑即到达、掉出平台边缘淘汰**；按到达顺序排名，第一个到达者获胜
- **烫手山芋 (Hot Potato)**：圆形石砖平台+玻璃围墙+随机障碍物；唯一一颗山芋开局随机发放，**固定寿命（默认 20 秒）**，**左键攻击其他玩家传递**（不刷新倒计时），时间到爆炸淘汰持有者（纯特效无破坏）；传递冷却 0.2 秒，持有者获得速度 I；最后幸存者获胜

以上小游戏均为凑齐 4 人开赛（最少 2 人、最多 8 人）。

### Minecraft Party 2（分阶段移植）

在 **Fabric 1.21.1 同服**运行的玩法移植，当前为第一阶段 **Quick Play：每场选择一个小游戏，排名结算后返回 PvP 大厅**。入场后手持快捷栏物品右键投票，10 秒后取票数最多的一项，同票随机；这段投票是本服匹配入口的适配规则。

- **掘战 Spleef（408）**：铁锹挖雪、沙与泥土，弓箭可破坏雪块；掉落出局，最后留在场上的玩家获胜。
- **领地争夺 Tile Capture（412）**：踩白色羊毛占地，禁止跳跃及穿越其他玩家的领地；右键回位棒返回安全位置，结束时按占地数排名。
- **红灯绿灯 Red Light, Green Light（424）**：绿灯前进、红灯停下；违规回起点，跑完 145 格赛道按到达顺序排名。限时 90 秒，未完赛者按最远进度、当前进度排名；当前采用普通难度的 19 tick 红灯反应窗口。
- **2~10 人、无需自选套件**。凑齐 4 人触发开赛；只有 2~3 人时等待 20 秒触发，之后进入正常入场倒计时。OP 可用 `/pvp start` 强制以当前人数开赛（至少 2 人）。海岛攻防使用相同的匹配规则。

### 海岛攻防 (Island Siege)

玩家随机分为**红方进攻 / 蓝方防守**。先进行 **240 秒（4 分钟）建造阶段**：蓝方搭建防线，红方在基地整备；随后红方有 **480 秒（8 分钟）进攻时间**，完成以下三项目标中的任意两项获胜，否则蓝方获胜。

- **占领旗帜**：在目标附近累计占领 30 秒，蓝方在场时暂停进度。
- **击败盔甲守卫**：击杀守卫目标区的武装守卫。
- **夺取金色骷髅**：右击铁笼并停留 5 秒解锁，蓝方接近会暂停；将骷髅带回红方基地完成目标，携带者死亡或离场会归还骷髅。
- 木桶提供随机补给，每 45 秒可再次领取；玩家死亡后回本队基地复活，并获得 3 秒保护。原地形受保护，玩家搭建的方块可拆除。
- **2~10 人、无需自选套件**，从趣味小游戏菜单或 `/pvp join islandsiege` 进入；匹配及 OP 强制开局规则同上。

当前保留原包的攻防流程和“三选二”目标，使用**原生重建的多路线立体岛屿**，含三种地形变化与随机掩体；原版建筑、全部自定义物品、射击小游戏和隐藏内容尚未完整复现。原包为 **1.21.8**，本服以 Java 会话实现独立对局。占旗 30 秒、开笼 5 秒、补给 45 秒、装备物资及守卫属性均为本次移植的原生平衡参数（守卫生命为 `60 + 20 × 红方人数`，基础攻击伤害 5），后续可继续对照原图调整。

### MyGO 枪战爆破

原版 Java 1.21.1 客户端下载服务器资源包即可游玩，无需客户端 Mod。枪械目录、阵营、经济与回合时限按停更前 **CS:GO 经典竞技** 实现：**MR15，先赢 16 回合，第 15 回合后换边，15:15 平局**。

- **入口与匹配**：指南针主菜单 → 空岛战争右侧的 MyGO，或 `/pvp join mygo`。首次选择下载资源包，加载成功后再次选择入队。保留本服 2～10 人（1v1～5v5）等员适配：满 10 人立即开局，至少 2 人等待 60 秒。奇数队列保留最后一人。OP `/pvp start` 可提前开局；少于 4 人不计正式战绩。
- **时限**：冻结 15 秒，解冻后仍可在本方购买区购买 20 秒；作战 115 秒。安装 C4 为 3.2 秒，安装后独立计时 40 秒；无拆包器拆除 10 秒，有拆包器 5 秒。回合结束保留 7 秒活动、拾枪和交战窗口。第 16 回合双方换边并重置装备、金钱与败补起始档。
- **操作**：持枪左键开火，F 换弹，Q 丢主枪/副枪/C4，数字键切枪；瞄具枪右键循环切换镜位后关镜。手持投掷物时，左键大力高抛、右键小力低抛，投出自动切回主枪/副枪，防止按住右键继续扔第二颗。第 6 格 C4/拆包工具在包点潜行右键开始，松潜行、移动或切枪取消。第 9 格购买器右键打开军械库，也可用 `/pvp mygo`、`/pvp mygo buy <商品>`、`/pvp mygo reload`。`/hub` 退赛；`/pvp leave` 退出排队。
- **34 把枪**：Glock-18、USP-S、P2000、P250、Five-SeveN、Tec-9、CZ75-Auto、Dual Berettas、Desert Eagle、R8；MAC-10、MP9、MP7、MP5-SD、UMP-45、P90、PP-Bizon；Galil AR、FAMAS、AK-47、M4A4、M4A1-S、AUG、SG 553；SSG 08、AWP、G3SG1、SCAR-20；Nova、XM1014、MAG-7、Sawed-Off；M249、Negev。T 默认 Glock-18，CT 默认 USP-S。商店支持独立更换副枪，阵营限制也约束手枪、经济步枪和自动狙；敌方掉落枪仍可拾取。
- **参数与来源**：价格、弹匣/后备、伤害、穿甲比例、距离衰减、射击周期、弹丸数、击杀奖励与镜位来自 Valve 公开游戏数据，并合入 2022 年 AWP 五发和 M4A1-S 20/80、远距衰减更新；来源及解析属性见 `src/test/resources/mygo/csgo-weapon-facts.json`。一格按一米换算 Source 射程，周期向上量化到 20 tick/s。换弹时长为动画时长近似，散布、压枪、碰撞盒仍为 Minecraft 适配。左键一次发射一发（霰弹独立追踪多颗弹丸），不再强制 AK/M4 三连发；精确按住/释放的全自动输入需要额外客户端支持。
- **开镜**：AK/M4、手枪、冲锋枪等不再开镜或获得开镜精度加成；AUG、SG 553 一级，AWP/SSG 08/G3SG1/SCAR-20 两级。AWP/SSG 08 开火会退镜拉栓，射击周期结束后恢复原镜位；切枪或换弹取消恢复。南瓜提供统一镜框，能力包仅调客户端 FOV 基准，真实权限和移速不变；AWP 镜位为 40°/10°，其余镜位按武器数据。以基础 FOV 70、视野效果 100% 为校准点，其他客户端设置会影响效果，不能宣称与 Source 投影逐像素一致。原版客户端真实 FOV 方法与包编解码测试见 `MyGoScopeTest`，实现说明见 `tools/mygo_scope_testing.md`。
- **经济**：每半场 $800，上限 $16000。歼灭/超时胜每人 $3250，炸包/拆包胜 $3500；安拆个人各 $300，T 安包后被拆额外每人 $800。败补档为 $1400/$1900/$2400/$2900/$3400，半场从 $1900 档开始，败后升一档、胜后降一档。击杀按枪械付奖：常规 $300、AWP/CZ75 $100、多数冲锋枪 $600（P90 为 $300）、霰弹枪 $900、刀 $1500。T 超时仍存活者无基础败金。
- **护甲与装备**：防弹衣/补甲 $650，满甲加头盔 $350，无甲衣盔套装 $1000，CT 拆包器 $400。护甲按命中部位消耗，残甲耗尽后不能继续提供完整减伤；下一回合存活者保留残甲和枪械并补充弹药，死亡/换边重置。主副枪可独立丢弃拾取；死亡掉落最佳枪械及 C4。
- **投掷物**：HE $300（第 4 格，最多 1）、闪光 $200（第 5 格，最多 2）、烟雾 $300（第 7 格，最多 1），合计最多 4 颗。左右键分别大力高抛/小力低抛，轨迹受重力、移动惯性和墙面/地面反弹影响。HE/闪光 1.5 秒引信；HE 使用距离衰减、遮挡与护甲减伤，闪光按距离/朝向/遮挡影响自己、队友和敌人。烟雾落稳后起烟，持续 18 秒，子弹可穿过。原版的按住拔栓/松键抛出及双键中等力度没有移植，使用纯服务端点击即抛的操作适配。未使用道具随存活者保留，死亡和换边清空。
- **脚步与环境声音**：普通移动/疾跑按实际步距播放石地、金属、木板、松软地面、水面等定位声音，潜行和地面低速移动安静，梯子/藤蔓攀爬按竖直位移发出木质步音；起跳、落地、切枪、拔栓、投掷物反弹和烟雾消散有独立声音。新版资源包在加载期间屏蔽原版移动音，避免本人客户端预测脚步与服务端脚步叠音；入队等待阶段也会安静，退包后恢复原版声音。步频、听距与音色是 Minecraft 适配，不是 Source 音频引擎逐项复刻。闪光使用原版失明/黑暗状态近似，没有完整复刻 CS:GO 白屏淡出与音频混音。
- **伤害结算**：34 枪的基础伤害、爆头倍率、穿甲、距离衰减、弹丸数和最远射程已与停更前 CS:GO 分发数据逐项核对（204 项一致）。胸/臂 1 倍、腹部 1.25 倍、腿 0.75 倍，头部按各枪倍率；先计算距离与部位，再计算护甲，最终生命伤害向下取整、护甲消耗向上取整。腿不受护甲保护，头部仅有头盔时受保护，残甲不足时剩余伤害继续扣血，甲归零时头盔也失效。霰弹保留同枪弹丸的小数中间精度，合计后结算。命中部位按当前 Minecraft 站立/潜行碰撞盒高度分区，几何并非 CS:GO 动画命中盒。
- **HUD 与公平**：快捷栏上方加粗金色金钱，显示 HP、残甲、K/D、弹药及换弹进度。100 虚拟 HP，枪械不能挖图或造成原版工具近战伤害。当前友伤关闭，友军不挡弹，未实现墙体穿透、完整部位碰撞盒与服务器历史位置回溯。正常结束、退赛及断线恢复赛前快照；仍不支持本场中途重连，阵亡后在封闭室等待下一回合。
- **地图**：使用 [LesRaisins 的 Dust II Minecraft 复刻](https://www.curseforge.com/minecraft/worlds/lesraisins-csgo-dust-ii)，作者 LeComte / LesRaisins Studio，发布者 xjqsh。地图只导入静态建筑，双方各 5 个出生/朝向、购买区和 A/B 双包点独立配置；开始前检查实际净空和地板，错误则取消并恢复快照。原图仅允许保留版权信息的非商业使用；完整声明在 Mod 内 `pvp/mygo/maps/NOTICE.txt`。来源、坐标与重现工具见 `tools/assets/mygo-dust2/`、`tools/extract_mygo_map.py`、`tools/audit_mygo_map.py`。
- **地图布局与安全**：T 从匪家高地出发，CT 从中路桥下低层出发；A 在原图红色下包标记，B 在默认箱体前方，购买区随出生区域同步。全图地面、台阶及屋顶均合法，不再按隐藏坐标判“离开战场”阵亡；掉出地图或误入其他世界时返回最近安全落脚点，保留 HP、装备与回合状态。坐标和地形核对记录见 `tools/assets/mygo-dust2/layout-notes.md`。
- **战绩**：`/pvp mygo stats` 保存至 `config/pvp/mygo/stats.json`，不影响其他模式隐藏分。OP `/pvp mygo status` 可检查本人枪械、镜位、购买时限、护甲、经济档位、回合与包点。

资源包的 34 枪轮廓、材质、开火/换弹姿态及声音为本项目原创 MIT 资源，新增脚步/投掷环境音也是原创单声道合成；见 ZIP 内 `MYGO_ASSETS_LICENSE.txt` 与 `MYGO_ASSETS_source.json`，不包含 Valve 游戏模型、贴图或原版声音。[Valve 公开政策](https://store.steampowered.com/video_policy)不允许拆出游戏资产单独分发，因此没有从网络音效包复制原声。已有合法音源可通过生成器的 `--authorized-audio-dir` 与 `--audio-license-file` 导入，生成器校验单声道 OGG 并记录来源声明。旧 Weapon Pack / CS4M 参考的历史来源与许可仍保留在仓库。物品贴图均放在 `textures/item/mygo/`，使用原版图集与 CustomModelData，无需 OptiFine。

### 起床战争 (Bed Wars)
加载 **Hypixel Solo-Doubles 风格 8 人地图**（1.21.1 世界存档，放在 `config/pvp/bedwars/maps/<地图名>/`，自动探测 8 队床位置）；**Solo（每队 1 人，最多 8 队）/ 双人（每队 2 人，最多 16 人）**两种模式。开局在等待大厅倒计时，然后传送到各自队伍岛；**摧毁敌方床**（该队无法复活）并**淘汰所有人**获胜。
- **有床死亡延迟 5 秒复活**（旁观者回本队岛等待+标题倒计时，复活后抗性 V 保护；等待期间床被摧毁则直接淘汰）、无床淘汰变幽灵；**本队床被摧毁时全队标题警告**
- **每队铁（1 秒/次，概率一次掉 2~4 个）/金（2 秒/次，概率多掉 1 个）生成器**定时刷资源；中央岛刷钻石/绿宝石
- **右击商店实体购买**：村民=道具商店（分类标签页），僵尸=团队升级（按序逐级购买）
- 地图本体不可破坏（床除外），可自由搭方块；采用 1.8 低版本战斗；凑 2 人即开赛（按人数动态启用队伍）

## 服务端安装

1. 准备一个 **Fabric Loader** 的 1.21.1 服务端：到 [fabricmc.net](https://fabricmc.net/use/server/) 下载并运行 `fabric-server-launch.jar`（选择 1.21.1），生成 `mods/` 目录。
2. 将本 Mod 的 jar 放到服务端 `mods/` 目录，同时放一份 **Fabric API**（`fabric-api-0.116.x+1.21.1.jar`，从 [Modrinth](https://modrinth.com/mod/fabric-api) 或 CurseForge 下载，版本匹配 1.21.1）。
3. 启动服务端。首次启动会在 `config/pvp/` 生成 `config.json` 和 `kits.json`（默认配置）。
4. 启动日志出现 `[PvP] 竞技场世界已创建` 即表示正常。

> 竞技场使用独立的虚空维度 `pvp:arena`，运行时创建、不写入存档，每次重启都是全新虚空。
>
> **战斗机制**：饱食度按原版规则消耗（战斗/冲刺会饿），**吃东西可以回血**（套件自带熟牛肉）。

## 游戏内 GUI

进服后快捷栏自动发放 **§6PvP 竞技场** 指南针（第 9 格优先），**右键**打开菜单；也可输入 `/pvp` 或 `/pvp menu`。

主菜单：
- 🗡 **PvP 对战** → 子菜单：**1v1 / 2v2 / FFA / 相扑 / 死斗** → 选择套件即加入队列
- 🏝 **空岛战争** → 点击直接加入队列，入场后选择职业；可提前预览职业
- 🔫 **MyGO 枪战爆破** → 位于空岛战争右侧；首次加载资源包后再次点击加入队列
- 🧱 **战桥** → 子菜单：**1v1 / 1v1v1v1 / 2v2 / 混战**（装备固定），点击直接加入队列
- 🎮 **趣味小游戏** → 子菜单：**幸运之柱 / TNT 跑酷 / 心跳水立方 / 烫手山芋 / Minecraft Party 2（移植中）/ 海岛攻防**（无需自选套件），点击直接加入队列
- 🛏 **起床战争** → 子菜单：**Solo（每队 1 人）/ 双人（每队 2 人）**，点击直接加入队列
- 🤺 **向玩家发起决斗** → 选择在线玩家 → 选择套件 → 发送决斗邀请
- 📊 **我的战绩**、📦 **查看套件列表**
- 🚪 **离开队列**（排队中才显示）

> 菜单为服务端实现的原版容器界面（箱子），原版客户端直接可用。
>
> **排队时**快捷栏会出现红色「§c离开排队§r」红石粉，右键即可退出排队（开赛时自动移除）。
>
> **OP 立即开赛**：排队中打开主菜单，OP(2 级+) 会看到「§a立即开始」按钮（或用 `/pvp start`），可跳过倒计时直接以当前队列人数开赛。
>
> **大厅保护**：不在对局中的玩家为冒险模式、无敌、饱食度不掉（可在配置中关闭）。

内置套件 ID：`sword`（剑战）、`bow`（弓箭）、`full_gear`（全装备）、`iron_pvp`（铁套PVP）、`sumo`（相扑击退棍）、`no_debuff`（NoDebuff 药水PvP）、`gapple`（金苹果）、`axe`（斧战）、`legacy_1_8`（1.8 经典：钻石剑+全套铁甲+8金苹果+速度II，**自带 1.8.7 战斗手感**），以及 `kits.json` 中自定义的套件（用其 `name` 字段调用）。**空岛战争/战桥/趣味小游戏/起床战争/村庄保卫战/色盲派对不需要套件**；需要选套件的是 1v1 / 2v2 / 自由乱斗 / 相扑 / 死斗。

## 床战地图标记

Bed Wars 地图的商店 / 铁金生成点 / 钻石绿宝石生成点需要精确标注，用游戏内标记模式操作（OP 2 级）：

1. `/pvp bedwars edit <地图名>`：加载地图到竞技场，传送到地图上空（创造+飞行），快捷栏发放标记物品
2. 用快捷栏物品标记（**左键标记，右键取消**；标记点放在点击方块的上方一格，用粒子+方块可视化）：
   - 🟢 木棍 = 普通商店
   - 🟣 烈焰棒 = 团队升级商店

## 隐藏分（内部，不展示）

除玩家可见的胜/负/场次外，系统还给每位玩家维护一个 **隐藏分**（Elo/MMR），初始 **1600**。
它**不出现在任何玩家界面上**——聊天、计分板、`/pvp stats`、`/pvp top`、GUI 都只显示胜率与胜负场次；
隐藏分只作为系统计算工具，目前唯一用途是**空岛弱势补偿**。

- **补偿为什么看隐藏分**：胜率会把"打得多"和"打得好"混在一起，而且强者总被排在一起、胜率趋近 50%，
  用它排强弱会补偿错人。隐藏分按"对手是谁"刻画水平，与场次多少无关；新号从 1600 起步，不会被当成"胜率 0"的弱者。
- **两人对局**是标准 Elo：`期望胜率 = 1 / (1 + 10^((对手分 − 自己分) / 400))`，常规 `K = 32`，新号前 10 场 `K = 48`。
- **多人/多队**（FFA、空岛、起床、乱斗）用同一公式的推广（Bradley–Terry 多项分布）：赢下 N 队局拿 `K × (1 − 1/N)`、每支输队只扣 `K / N`，全场总变化为 0，平均分长期稳定在 1600 附近。
- **队友之间不结算**：同队用"队内平均分"代表整队，队伍的变化每人各拿一份。
- **没有胜负对立的局不结算**：如村庄保卫战全员守住（或全员失败）、无人完赛的竞速，只记录场次。

## 对局流程

1. 玩家加入队列（或接受决斗），凑齐人数后自动开赛。
2. 快照每位玩家的背包/位置/生命/效果 → 传送到竞技场 → 发放套件 → 5 秒倒计时。
3. 开战后：1v1/2v2 以整队被淘汰判定胜负；FFA 等乱斗模式最后一个存活者获胜。
4. 结束：公布胜负 → 恢复玩家原状态并传回 → 记录战绩（并静默更新隐藏分）→ 清空场地，等待下一场。
5. 中途掉线判负；掉入虚空判负；淘汰后转为旁观视角观战。

## 对战体验细节

- **UI 工具不可丢弃**：主菜单指南针、排队红石、观战物品均无法扔出（防止误丢）。
- **组队关闭友伤**：2v2 等组队模式下队友之间无法造成伤害（也不会击退队友）；FFA/空岛战争/幸运之柱仍为全员互伤。
- **胜利庆祝**：一方获胜后不会立刻结算，先在胜者头顶**发射烟花**并显示「你赢了！」大字，5 秒后结算恢复。
- **死亡幽灵**：**死亡不弹死亡界面**，直接转为**旁观者模式幽灵**——空物品栏（身上物品**爆落在地**供其他玩家拾取）、无敌、**隐身**、**可自由飞行**，**无法与对局任何交互**；靠近掉落物时会被**向上弹开**，等比赛结束自动恢复回主城。
- **右侧信息栏**：对局中屏幕右侧计分板实时显示——模式（按类型着色）、比赛计时、各队成员与存活状态（存活绿色●、淘汰灰色✝）；空岛战争额外显示缩圈倒计时/安全半径。侧边栏只对参战玩家显示，回主城自动隐藏。
- **登录清空**：加入服务器时先清空背包再发放 UI 工具，不会出现背包挤满导致拿不到指南针。
- **可抛 TNT**：竞技场内拿到 TNT 后，**对空中右键把 TNT 抛射出去**（4 秒引信、落地/命中即爆）；对准方块右键仍是原版放置。
- **主城 TNT 无害**：主世界的 TNT 爆炸不破坏方块、不误伤玩家（保留声音/粒子）；只有竞技场内才会炸地形。
- **可抛火焰弹**：火焰弹右键即发射，命中时把周围 5 格玩家（含投掷者自己）沿"爆炸→自身"方向统一径向震开——往脚底扔会被弹上天（火焰弹跳），炸旁边的人会被震落岛。
- **空岛击退球**：只有箱子中带专用标记的「击退球」会在有效命中时增加击退；普通粘液球无额外效果，也不会在无敌帧期间重复叠加。
- **空岛不死图腾**：背包图腾可抵挡致死伤害；虚空救援在实际淘汰线前 10 格触发，回到仍有效的安全落脚点，恢复 8 点生命并给短暂保护，缩圈淘汰无效。
- **敌人追踪罗盘**：空岛战争开出的追踪罗盘实时指向最近的敌人。
- **空岛基础补偿**：比本局隐藏分中位数低 150／300 分时，初始出生岛增加 1／2 档补给，每档仅 8 方块、2 食物；同分待遇相同，装备、附魔和神器概率统一。隐藏分本身不对玩家显示。

需要网络下载依赖（首次约 5-10 分钟）。机器需可运行 Gradle 9（Java 21 会自动下载）：

```bash
./gradlew build
```

产物位于 `build/libs/pvp-1.0.0.jar`。
