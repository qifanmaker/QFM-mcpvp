# PvP 匹配 Mod（MC 1.21.1 · Fabric 服务端）

一个纯服务端的 PvP 匹配 Mod：支持 **1v1 / 2v2 / 自由乱斗(FFA) / 相扑(Sumo) / 1.8 经典PvP / 空岛战争(SkyWars) / 战桥(Bridge)** 对战，支持**队列自动匹配**与**决斗挑战**，可自选**装备套件**（剑战 / 弓箭 / 全装备 / NoDebuff / 自定义 JSON 配置等）。每场比赛在**专用虚空竞技场维度**中生成独立地形，结束后销毁重建。

- **自由乱斗**：凑齐 3 人开始 60 秒倒计时，期间达到 6 人自动加速到 10 秒内开赛（人数不限，每人用自己的套件）
- **相扑**：不吃伤害只吃击退，落到平台下方 20 格淘汰（套件带一组末影珍珠可救回），最后一个留在场上的人获胜
- **1.8 经典PvP**：模拟 1.8.9 手感——**无攻击冷却**（疯狂点按打满伤害）、剑**格挡减伤 50%**（右键格挡、攻击解除），配速度 II
- **空岛战争 (Beta)**：每人随机一座出生空岛（3 箱），到**巨大的中间主岛**（半径约 45、**10 箱均匀散布**）之间有**一座中途岛**（半径约 8、3 箱，作为搭桥跳板）；地图大幅放大、出生岛离主岛更远（中岛扩大后 gap 不变），**各岛间有 ±3 格高低差**；**无套件、生存模式开箱搜装备**，采用 **1.8 低版本战斗**（无攻击冷却、剑可格挡减伤 50%）；武器/护甲随机附魔（最高 II 级、击退最高 1 级）；**极低概率**开箱出 **鞘翅+3 烟花火箭、妙人斧（锋利 666 金斧·耐久 1）、附魔金苹果、不死图腾**（掉虚空自动救回中岛）；**追踪罗盘**指向最近敌人；每场从 **主世界 / 地狱 / 冰原 / 末地** 随机抽取一个**主题**（地狱岛面刷灵魂沙与岩浆、冰原全是冰、末地中岛为空心环）；凑齐 4 人开赛（最少 2 人、最多 8 人），**3 分钟后缩圈**逼团（安全半径不小于主岛），最后幸存者获胜
- **战桥 (The Bridge)**：**双基地隔虚空相望，中央一座 1 格宽桥**，跳进对方基地中央的**球门洞**得 1 分，**先得 5 分获胜**；**死亡立即原地重生**、每个进球后全员回笼位 5 秒再放出，**玩家搭的方块不重置**；配 **铁剑 / 弓+1 支箭（每 4 秒回 1 支）/ 效率 II 钻石镐 / 128 个队伍色陶瓦 / 8 金苹果 / 队伍色皮革甲**，生存模式可放/拆方块（**地图本体拆不掉**，只能拆别人搭的）；采用 **1.8 低版本战斗**；四种模式：**1v1**（2 人）、**1v1v1v1**（四方各自球门）、**2v2**（4 人随机分队）、**混战**（偶数人数/2 分两队，2v2~4v4 均可）

- 原版客户端即可加入，**无需安装客户端 Mod**
- **游戏内 GUI 菜单操作**（无需记指令）：进服自动发一把「PvP 竞技场」指南针，右键打开菜单
- 进服自动显示「PvP 匹配 Mod vX.X.X」版本号，方便确认是否最新
- 所有消息为中文
- 战绩（胜/负/场次）持久化保存

## 服务端安装

1. 准备一个 **Fabric Loader** 的 1.21.1 服务端：
   - 到 [fabricmc.net](https://fabricmc.net/use/server/) 下载并运行 `fabric-server-launch.jar`（选择 1.21.1），生成 `fabric-server-launch` 启动方式与 `mods/` 目录。
2. 将本 Mod 的 jar 放到服务端的 `mods/` 目录，同时放一份 **Fabric API**（`fabric-api-0.116.x+1.21.1.jar`，从 [Modrinth](https://modrinth.com/mod/fabric-api) 或 CurseForge 下载，版本匹配 1.21.1）。
3. 启动服务端。首次启动会在 `config/pvp/` 生成 `config.json` 和 `kits.json`（默认配置）。
4. 服务端启动日志出现 `[PvP] 竞技场世界已创建` 即表示正常。

> 竞技场使用一个独立的虚空维度 `pvp:arena`，运行时创建、不写入存档，每次重启都是全新虚空。
>
> **战斗机制**：饱食度按原版规则消耗（战斗/冲刺会饿），**吃东西可以回血**（套件自带熟牛肉）。

## 游戏内 GUI

进入服务器后快捷栏会自动发放一把 **§6PvP 竞技场** 指南针（快捷栏第 9 格优先），**右键**即可打开菜单；也可以直接输入 `/pvp` 或 `/pvp menu`。

主菜单支持：
- 🗡 **1v1 / 2v2 / FFA / 相扑 / 1.8 匹配** → 进入套件选择页 → 点击套件即加入队列
- 🏝 **空岛战争 (Beta)** → 无套件，**点击直接加入队列**
- 🧱 **战桥 1v1 / 1v1v1v1 / 2v2 / 混战** → 无套件（装备固定），**点击直接加入队列**
- 🤺 **向玩家发起决斗** → 选择在线玩家 → 选择套件 → 发送决斗邀请
- 📊 **我的战绩**、📦 **查看套件列表**
- 🚪 **离开队列**（排队中才显示）

> 菜单为服务端实现的原版容器界面（箱子），原版客户端直接可用，无需任何客户端 Mod。
>
> **排队时**快捷栏会出现一个红色「§c离开排队§r」红石粉，**右键即可退出排队**（开赛时自动移除）。
>
> **OP 立即开赛**：排队中打开主菜单，OP(2 级+) 会看到「§a立即开始」按钮（或用 `/pvp start`），可跳过倒计时/等待直接以当前队列人数开赛（人数不足时会提示）。
>
> **大厅保护**：不在对局中的玩家为冒险模式、无敌、饱食度不掉（可在配置中关闭）。

## 命令

| 命令 | 说明 |
|---|---|
| `/pvp` 或 `/pvp menu` | 打开游戏内 GUI 菜单 |
| `/pvp join <1v1\|2v2\|ffa\|sumo\|1.8> <套件>` | 加入匹配队列 |
| `/pvp join skywars` | 加入空岛战争（无需套件） |
| `/pvp join bridge1v1\|bridge1v1v1v1\|bridge2v2\|bridge` | 加入战桥（无需套件；`bridge`=混战，需偶数人数） |
| `/pvp leave` | 离开队列 |
| `/pvp tpout` | 从竞技场返回主城（幽灵走旁观离开；活跃玩家视为弃权退出本场） |
| `/pvp tpin` | 从主城进入竞技场（有对局回到对局，无对局作为访客观看） |
| `/hub` | 返回主城（同 `/pvp tpout`） |
| `/watch` | 进入竞技场（同 `/pvp tpin`） |
| `/pvp start [主题]` | OP 专用：立即用当前队列人数开赛（跳过倒计时）；排空岛战争时可指定主题（`主世界`/`地狱`/`冰原`/`末地`） |
| `/pvp queue` | 查看自己排队状态 |
| `/pvp list` | 查看进行中的比赛与队列 |
| `/pvp stats [玩家]` | 查看战绩 |
| `/pvp top` | 胜场排行榜 |
| `/pvp kit list` | 查看可用套件 |
| `/pvp reload` | 重载配置（需要 OP 2 级） |
| `/pvp debug skywars [轮数]` | 生成随机空岛并传送查看（OP 2，测试用，不影响对局） |
| `/pvp debug skywars theme <主题>` | 生成指定主题的空岛（主世界/地狱/冰原/末地） |
| `/pvp debug skywars all` | 4 种主题各生成一张（区域 900~903），方便对比 |
| `/duel <玩家> [套件]` | 向指定玩家发起 1v1 决斗 |
| `/duel accept [挑战者]` | 接受决斗 |
| `/duel deny [挑战者]` | 拒绝决斗 |

内置套件 ID：`sword`（剑战）、`bow`（弓箭）、`full_gear`（全装备）、`iron_pvp`（铁套PVP）、`sumo`（相扑击退棍）、`no_debuff`（NoDebuff 药水PvP）、`gapple`（金苹果）、`axe`（斧战）、`legacy_1_8`（1.8 经典：钻石剑+速度II+金苹果），以及 `kits.json` 中自定义的套件（用其 `name` 字段调用）。**空岛战争不需要套件**，装备全部来自地图箱子。

### `config/pvp/kits.json`

自定义套件，示例：

```jsonc
{
  "kits": [
    {
      "name": "铁套测试",
      "items": [
        { "id": "minecraft:iron_sword" },
        { "id": "minecraft:bow" },
        { "id": "minecraft:arrow", "count": 32 }
      ],
      "armor": [
        { "id": "minecraft:iron_helmet" },
        { "id": "minecraft:iron_chestplate" },
        { "id": "minecraft:iron_leggings" },
        { "id": "minecraft:iron_boots" }
      ],
      "effects": [
        { "effect": "minecraft:speed", "duration": 6000, "amplifier": 0 }
      ],
      "food": 20,
      "saturation": 20.0,
      "gamemode": "adventure"
    }
  ]
}
```

- `items`：按顺序放入主手与快捷栏（最多 9 格）
- `backpack`：放入主背包的物品（适合不堆叠的物品，如岩浆/水桶）
- `armor`：顺序为 头盔/胸甲/护腿/靴子
- `effects`：战斗中的状态效果
- 修改后执行 `/pvp reload` 生效

### `config/pvp/stats.json`

战绩数据，由 Mod 自动维护，无需手动编辑。

## 对局流程

1. 玩家加入队列（或接受决斗），凑齐人数后自动开赛。
2. 快照每位玩家的背包/位置/生命/效果 → 传送到竞技场平台 → 发放套件 → 5 秒倒计时。
3. 开战后：1v1/2v2 以整队被淘汰判定胜负；FFA 最后一个存活者获胜。
4. 结束：公布胜负 → 恢复玩家原状态并传回 → 记录战绩 → 清空平台地形，等待下一场。
5. 中途掉线判负；掉入虚空判负；淘汰后转为旁观视角观战。

## 对战体验细节

- **UI 工具不可丢弃**：主菜单指南针、排队红石、观战物品均无法扔出（防止误丢）。
- **组队关闭友伤**：2v2 等组队模式下队友之间无法造成伤害（也不会击退队友）；FFA/空岛战争仍为全员互伤。
- **胜利庆祝**：一方获胜后不会立刻弹出，先在胜者头顶**发射烟花**并显示「你赢了！」大字，5 秒后结算恢复。
- **死亡幽灵**：**死亡不弹死亡界面**，直接转为**冒险模式幽灵**——**空物品栏**（身上物品会**爆落在地**供其他玩家拾取）、无敌、**隐身**（不显示身体/手持物品、无隐身粒子）、**可自由飞行**，**无法与对局任何交互**（不能开箱/攻击/破坏/使用物品）；若场上玩家往幽灵脚下搭方块或幽灵靠近掉落物（会被吸取），幽灵会被**向上弹开**，等比赛结束自动恢复回主城。
- **右侧信息栏**：对局中屏幕右侧计分板实时显示——**模式（按类型着色）**、**比赛计时**（倒计时/已进行时间/结算中）、**各队成员与存活状态**（队友/对手用队伍颜色区分，存活绿色●、淘汰灰色✝）；空岛战争额外显示**缩圈倒计时/当前安全半径**。侧边栏只对参战玩家显示，**回到主城后自动隐藏**。
- **登录清空**：加入服务器时先清空背包再发放 UI 工具，不会出现背包挤满导致拿不到指南针。
- **空岛战争开箱**：出生岛 3 箱（**每箱保底两件铁质装备**——**60% 偏防具**，3 箱铁装几乎必齐；外加**两小叠搭桥方块**分散放置，不再一整大组）；铁质装备与**防具刷新整体上调**（含铲子/锄头/镐等**铁质杂项**）；**中等概率金斧**（普通/锋利 I~III，稀有**锋利 VII**，金斧耐久低属玻璃大炮）；**附魔削弱**——锋利/保护/力量**最高 II 级**（55% I / 45% II），**击退最高 1 级**；新增 **铁砧 + 经验瓶**（可合成/附魔）、**钓鱼竿**（命中把人击退）、**追踪罗盘**（指向最近敌人）、**雪球 ×16**、**低概率粘液球**（击退 III 近战武器）；金苹果与蜘蛛网刷新量上调；中间主岛箱子更富（钻石装为主，还会出**重锤**、更多 TNT/岩浆桶等）；**药水**含速度 I/II、跳跃 I/II、力量 I、生命恢复 I/II、瞬间治疗 I/II（饮用或喷溅）；中间岛每箱约 1.5% 概率出**极稀有物品**（鞘翅+3 烟花火箭、附魔金苹果、**不死图腾**各约 0.5%）；**秒人斧只刷新在玩家岛**（出生箱约 0.5%），玩家岛也可能出**不死图腾**（约 0.5%）。
- **可抛 TNT**：竞技场内拿到 TNT 后，**对空中右键会把 TNT 抛射出去**（4 秒引信、落地/命中即爆），可当远程武器或炸别人岛的陷阱；对准方块右键仍是原版放置。
- **主城 TNT 无害**：主世界（主城）的 TNT 爆炸**不破坏方块**、也不会误伤玩家（保留声音/粒子）；只有竞技场内才会炸地形。
- **可抛火焰弹**：火焰弹**右键即发射**（对准方块也会发射，不会点火），命中地面/玩家时播放**爆炸特效**，把周围 5 格玩家（**含投掷者自己**）沿"爆炸→自身"方向**统一径向震开**——往脚底扔会被弹上天（火焰弹跳），炸旁边的人会被震落岛。
- **粘液球击退 III**：空岛战争开出的粘液球是**近战武器**——**左键攻击**命中把目标**强力击退**（约击退 III），配合击退剑/钓鱼竿把人打下岛。
- **不死图腾救场**：持有不死图腾**掉入虚空**时自动消耗一个，把你传送回**中岛中心**救回（仅掉虚空触发，缩圈淘汰无效）。
- **敌人追踪罗盘**：空岛战争开出的「敌人追踪罗盘」会实时指向**最近的敌人**，方便寻人开打。
- **随机主题**：每场空岛战争从 **主世界 / 地狱 / 冰原 / 末地** 中随机抽取一种——地狱全部由地狱岩构成、岛面随机刷**灵魂沙**与**岩浆**；冰原**第一层为冰、下面为雪**；末地全由**末地石**构成、**中间主岛为空心环**（中央是虚空，箱子都摆在环上不会浮空，不死图腾救回点也自动落在环上）。
- **战绩弱势补偿**：每局把玩家按胜率从低到高排名，**胜率最低的 1~2 名**（双人局只补最低者）的出生岛/中途岛装备与神器概率会有**轻微**提升（附魔概率略高、保底铁装偶换钻石、神器概率略增），不算明显，仅作追赶机制。
- **空岛战争缩圈**：开赛 3 分钟后每 30 秒外圈塌掉 4 格，圈外玩家被淘汰，逼迫往中间打；被缩圈淘汰也算出局。
- **战桥玩法**：跳进对方基地中央的**球门洞**得 1 分（掉进自家球门不算分），**先得 5 分获胜**；**死亡立即在己方基地原地重生**（不出现死亡界面），每个进球后全员回笼位、无敌 5 秒再放出；玩家搭的方块**不重置**，且只有**自己放的方块能拆**（地图本体受保护）；弓每次 1 支箭，用完后每 4 秒回 1 支；1v1v1v1 为四方各自球门的混战，混战模式按总人数/2 平均分队。
